
# CAP BON EXPLORER
### Portail touristique interactif du Cap Bon

## 1. Présentation du projet

Cap Bon Explorer est un site web touristique qui permet aux visiteurs de découvrir les richesses naturelles, culturelles et artisanales de la région du Cap Bon en Tunisie.

Le site propose plusieurs activités touristiques, un agenda des activités, ainsi qu'un système de réservation permettant de simuler une réservation en ligne.

Ce projet a été réalisé dans le cadre du module **Développement Web côté client** à l'ISET Nabeul.

## 2. Objectifs du projet

Les principaux objectifs sont :

- Présenter les différentes activités touristiques du Cap Bon.
- Faciliter la recherche et le filtrage des activités.
- Permettre aux visiteurs de consulter les détails de chaque activité.
- Proposer un agenda des activités.
- Simuler une réservation avec calcul automatique du prix et des réductions.
- Permettre aux visiteurs de contacter le site à travers un formulaire.
- Créer une interface responsive adaptée aux ordinateurs, tablettes et téléphones.

## 3. Technologies utilisées

Les technologies utilisées pour développer ce projet sont :

- **HTML5 :** Structure et organisation des pages web.
- **CSS3 :** Mise en forme et personnalisation du design.
- **JavaScript :** Gestion des interactions, recherche, filtrage, calcul des prix et validation des formulaires.
- **Bootstrap 5.3 :** Création d'une interface responsive et utilisation de composants comme les cartes, la navbar et les modals.

## 4. Fonctionnalités principales

Le site comprend cinq pages principales :

- **Accueil (index.html) :** Présentation du projet et découverte du Cap Bon.
- **Activités (activites.html) :** Affichage des activités, recherche, filtrage par catégorie et consultation des détails.
- **Agenda (agenda.html) :** Présentation du programme des activités.
- **Réservation (reservation.html) :** Sélection d'une activité, choix du nombre de participants et calcul automatique du montant avec les éventuelles réductions.
- **Contact (contact.html) :** Formulaire permettant aux visiteurs de saisir leurs informations et d'envoyer un message de manière simulée.

## 6. Installation et lancement

Pour lancer le projet :

1. Télécharger ou décompresser le dossier du projet.
2. Ouvrir le dossier dans Visual Studio Code.
3. Ouvrir le fichier `index.html` dans un navigateur web.
4. Il est également possible d'utiliser l'extension Live Server pour lancer le site.

**Remarque :** Une connexion Internet est nécessaire pour charger Bootstrap depuis son CDN.

## 8. Remarque importante

Ce site est un projet pédagogique réalisé à des fins de démonstration.

Le système de réservation est simulé : aucune réservation réelle n'est effectuée, aucun paiement n'est réalisé et aucune donnée n'est envoyée à un serveur.
